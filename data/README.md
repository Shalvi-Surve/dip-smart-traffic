# DAWN dataset

The existing local collection is browsable from **Batch processing → Bundled DAWN samples**. The CSV at `metadata/dawn_sample_manifest.csv` records filename, weather category, relative sample path, source dataset, source link, attribution, DOI/version and license. Current local rows total 1,027 (fog 300, rain 200, sandstorm 323, snow 204); the published landing page describes 1,000, so treat this as a local acquisition/version discrepancy.

Source: Mourad A. Kenk and Mahmoud Hassaballah, DAWN, Mendeley Data v3, DOI `10.17632/766ygrbt8y.3`. The source page lists CC BY-NC 3.0 and prohibits commercial use/distribution. Attribute the dataset and recheck source terms before redistributing images. This is existing user-provided data; the application does not download it. Its categories and bounding boxes are not clean-weather reference pairs and are not used as enhancement labels.
